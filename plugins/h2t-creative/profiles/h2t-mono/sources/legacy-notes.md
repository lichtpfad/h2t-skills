# h2t-mono Legacy Notes

Source: specdesigner.netlify.app

## Visual Grammar

**Typography**
- Single font stack: JetBrains Mono or system monospace
- All text same weight — differentiation through spacing only
- Uppercase labels, no serif, no sans-serif

**Color System**
- bg: #0d0d0d
- accent: #e8352b (SpecDesigner red)
- text-dim: for secondary labels
- border: sparse 1px lines only

**Layout Motifs**
- Two-column split with 1px background separator
- Comparison table: sparse borders, `is-good`/`is-bad` state classes
- Zero decoration — no brackets, no glow panels, no cards

**Forbidden Patterns**
- No HUD brackets or corner marks
- No glow or text-shadow
- No rounded cards or pills
- No box-shadow
- No generic shared pricing/testimonials/features-grid
