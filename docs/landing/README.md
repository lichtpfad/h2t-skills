# Публичный лендинг пака

Исходник страницы, объясняющей пак: пять плагинов, установка, устройство скилла,
сессии, gather, progressive disclosure, онтология, vault, конфигурация, коннекторы.

| что | где |
|---|---|
| исходник | `docs/landing/recipe.yaml` (этот репозиторий) |
| собранная страница | `skills/index.html` в `lichtpfad/h2t-landings` |
| публичный адрес | https://lichtpfad.github.io/h2t-landings/skills/ |

Собранный HTML здесь **не хранится** — только рецепт. Копия артефакта в двух репозиториях
разъезжается молча; рецепт этой болезни не подвержен, потому что страница из него
воспроизводится.

## Пересборка и деплой

```bash
# 1. Собрать: рецепт → dist/ (три файла)
h2t-creative assemble --profile h2t-graphs --type landing \
  --recipe docs/landing/recipe.yaml --out /tmp/landing-dist

# 2. QA обязательна: 375 / 768 / 1440, переполнение и консоль
#    (скилл предписывает playwright-agent, которого нет — см. #460;
#     до его появления проверять через /browse)

# 3. Схлопнуть в один файл — конвенция h2t-landings: самодостаточный index.html
#    base.css + profile.css уезжают в <style>, внешних ссылок не остаётся

# 4. Положить в h2t-landings/skills/index.html, закоммитить, запушить в main.
#    GitHub Pages раздаёт из main, корня репозитория; отдельного шага деплоя нет.
```

Ссылка на страницу стоит в дашборде `h2t-landings/index.html`, в строке `h2t-skills`.

## Профиль

`h2t-graphs` из `plugins/h2t-creative/profiles/` — та же эстетика, что у
`graphs.lichtpfadstudio.com`: фон `#060609`, акцент `#e94560`, Inter для заголовков,
JetBrains Mono для остального. Смена эстетики — одна строка `profile:` в рецепте.

Три места, где рецепт выходит за рамки профиля, и почему:

- `<style>` в теле первой секции — у ассемблера нет ручки для дополнительного CSS
  (`assembler.py:88` линкует ровно два файла), а профиль не описывает ни таблиц, ни
  карточек, ни блоков кода. Поле `body` проходит через фильтр `safe`, чем это и решается.
- CSS-счётчик на `.section__label` — шаблон печатает `// SECTION` над каждым заголовком,
  тринадцать раз подряд. Счётчик даёт `// 01 … // 13` без правки профиля.
- `font-variant-ligatures: none` в блоках кода — JetBrains Mono склеивает `--` в одну
  черту, и `uv tool install --editable .` читается с экрана неверно.
