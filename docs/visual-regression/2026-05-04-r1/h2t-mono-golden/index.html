FAQ
How is this different from draw.io?

draw.io draws diagrams. SpecDesigner makes each diagram node a structured spec with boundaries, acceptance criteria, and code mapping. Diagram and spec are one object — they never diverge.

Why not just write a good CLAUDE.md?

CLAUDE.md is one file for your entire project. It doesn't scale past 5-10 modules. SpecDesigner compiles per-module specs — each agent gets only the context it needs.

Does it work with Cursor / Codex / other agents?

Yes. SpecDesigner compiles to standard Markdown files. Any agent that reads files works: Claude Code, Cursor, Codex, Windsurf, GitHub Copilot. MCP Server also available.

Is it open source?

The product is closed source. The Agent Spec Template (spec format) is open and free to use. Early access is free for focus group participants. Pricing TBD after feedback.

What does "forced clarity" mean?

The spec template (summary, boundaries, acceptance criteria, code mapping) forces you to think through each module before coding. Users report this is valuable even without an AI agent.
