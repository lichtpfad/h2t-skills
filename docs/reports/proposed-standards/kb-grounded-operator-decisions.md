## TL;DR
Before surfacing a decision to the operator, consult the relevant knowledge base or run the required research. Present a reasoned recommendation alongside the question. The operator's role is value/calibration sign-off, not method selection. Bringing an open question without a researched recommendation is a protocol violation.
