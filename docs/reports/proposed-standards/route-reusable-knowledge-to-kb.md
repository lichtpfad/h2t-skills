# Route Reusable Reference Knowledge to a Council-Verified KB, Not Siloed Project Docs

**Proposed home:** `C:/dev/docs/standards/route-reusable-knowledge-to-kb.md` (NEW)
**Track:** process · **Recurrence:** 2 lineage(s) · **Domain-independence:** medium

## TL;DR
When a research finding or reference conclusion will be reused across sessions or projects, it must be promoted to a shared, council-verified knowledge base with a citable reference — not left as a one-off section in a project plan or session doc. Promotion requires a gated ingest (not a raw dump): the material must pass a quality check before entering the KB. Per-project docs are for project-specific conclusions only; cross-cutting knowledge belongs in the shared KB where it can be cited and updated in one place.
